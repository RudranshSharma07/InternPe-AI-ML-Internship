# InternPe AI/ML Internship

This repository contains the projects completed during my **6-week AI/ML Internship at InternPe**.

The internship provided hands-on experience in data preprocessing, machine learning, classification, regression, neural networks, and practical model development.

## Internship Details

- **Organization:** InternPe
- **Domain:** Artificial Intelligence & Machine Learning
- **Duration:** 6 Weeks

## Projects

### 1. Diabetes Prediction
Machine learning classification project for predicting whether a person is diabetic based on medical diagnostic features.

**Techniques:** Data Preprocessing, Standardization, Support Vector Machine (SVM)

---

### 2. Car Price Prediction
Machine learning project for predicting the estimated price of a used car based on car-related features.

The project also includes a Flask web application for demonstrating the trained model.

**Techniques:** Data Cleaning, Linear Regression, Model Prediction, Flask

---

### 3. IPL Winning Team Prediction
Machine learning project for predicting the winning team in an IPL match using match-related data.

**Techniques:** Data Preprocessing, Machine Learning, Classification

---

### 4. Breast Cancer Detection
A classification project using Machine Learning and Neural Networks for breast cancer detection.

**Techniques:** Data Preprocessing, Neural Networks, Classification, Model Evaluation

---

### 5. Spam Mail Prediction
Machine learning project for classifying emails as spam or legitimate using email content.

**Techniques:** Natural Language Processing (NLP), Text Processing, Machine Learning, Classification

---
